# 에이전트 위키

공개 문서의 정본은 [`content/docs/`](content/docs/)입니다. 이 위키에는 원본에서 컴파일한 최종 콘텐츠인 `outputs/`만 둡니다.

위키를 읽고 만들 때의 현재성 원칙은 이 README가 정본입니다. 현재 의도와 시점을 먼저 확인하고, 원문·컴파일 지식·자동화 결과의 역할을 섞지 않습니다. 과거 자료는 현재 판단을 보강할 때만 쓰며, 재사용 가능한 결과만 위키에 남깁니다. 작업 이력·원문·운영 규칙은 Knowledge Lab이 소유합니다.

- 중앙 목차: [`content/docs/index.mdx`](content/docs/index.mdx)
- 운영 로그·일지·ingest 원장: Knowledge Lab 저장소가 소유합니다.
