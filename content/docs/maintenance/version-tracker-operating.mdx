# 버전 트래커 운영 원칙

버전 트래커는 단순한 최신 버전 목록이 아니라 업그레이드 판단 원장이다. 값이 바뀌었는지보다, 그 변화가 실제 운영 행동을 요구하는지를 분리해서 기록한다.

## 판단 기준

- `latest`는 출처에서 확인한 실제 최신값만 기록한다.
- `current`와 `latest`는 같은 표면에서 비교하고, 접두사 차이는 비교 전에 정규화한다.
- `notes`에는 업그레이드 판단에 필요한 변화, 호환성, 재검토 항목만 남긴다.
- patch 수준 변화는 조용히 넘기되, 애플리케이션 버전 변화나 호환성 이슈가 있으면 별도로 검토한다.
- minor/major 변화는 값만 갱신하지 않고 설정, 매니페스트, CRD, 동기화 옵션 같은 실행 점검 항목까지 함께 남긴다.
- 갱신 자동화는 실제 출처를 조회해야 하며, no-op은 연결 확인을 위한 임시 단계로만 허용한다.

## 적용 방식

트래커가 바뀌면 먼저 `current`와 `latest`의 차이를 운영 리스크로 번역한다. 즉시 조치가 필요하지 않은 patch 알림은 소음으로 취급하고, 설정 재검토가 필요한 major 변화는 근거 링크와 확인할 표면을 함께 남긴다.
