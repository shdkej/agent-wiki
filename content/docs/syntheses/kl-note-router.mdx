# KL Note Router

- 출처: `source/openclaw-system/data/daily-reviews/2026-08-26-review.md`, `source/openclaw-system/data/daily-reviews/2026-08-27-review.md`, `source/openclaw-system/reports/daily-archive/2026-08-26-kl-note-router/index.html`
- 역할: Obsidian, Knowledge Lab, Agent Wiki, Prompt Archive 사이의 원자료 라우팅 규칙을 압축한 synthesis
- 상태: 초안 · 저장소 통합이 아니라 목적지 분리와 편집 경계를 먼저 고정

## 한 줄 요약

흩어진 메모를 하나의 저장소로 합치는 대신, `원자료 → 분류 / 편집 / 삭제 / 소재화 → KL / Wiki / Prompt Archive / Threads`로 보내는 규칙이 필요하다.

## 핵심 판단

- Obsidian은 날것의 생각과 개인 기록을 두는 곳이다.
- Knowledge Lab은 선별된 지식만 받는 중간 저장소다.
- Agent Wiki는 다시 읽고 답할 수 있게 압축한 설명층이다.
- Prompt Archive는 반복 실행 가능한 프롬프트와 스킬 자산을 모아 두는 곳이다.
- Threads 같은 공개 표면은 비밀키, 내부 문서, 운영 규칙, 사적 맥락을 빼고 나서만 검토한다.

이 구조에서 중요한 것은 더 많은 저장소가 아니라, 어떤 입력을 어디로 보낼지 먼저 정하는 일이다. 원자료를 곧바로 합치면 맥락이 섞이고, 요약을 너무 일찍 하면 다시 쓸 수 있는 판단이 사라진다.

## 라우팅 순서

1. 원자료를 그대로 남길지 먼저 본다.
2. 재사용 가능한 판단만 KL 후보로 올린다.
3. 질문에 답할 수 있는 압축본은 Wiki로 보낸다.
4. 반복 실행할 수 있는 문장과 틀은 Prompt Archive로 보낸다.
5. 공개 발행 후보는 비밀 정보와 운영 경계를 제거한 뒤에만 남긴다.

## 편집 경계

- `분류`는 묶는 일이고, `편집`은 줄이는 일이며, `삭제`는 아예 남기지 않는 일이다.
- `소재화`는 메모를 글감 후보로 바꾸는 단계다.
- 긴 노트는 목차 10개를 넘기지 않는 쪽이 읽히기 쉽다.
- 불릿이 8개를 넘으면 더 이상 단순 메모가 아니라 재편집 대상이다.

## 운영 메모

- 이 라우터는 노트를 더 많이 쌓는 장치가 아니라, 썩기 전에 목적지로 보내는 장치다.
- AI 계정이나 공개 글은 사람 같은 리듬을 가질 수 있지만, 안전선보다 앞설 수는 없다.
- 2026-08-27 리뷰는 여행을 소비가 아니라 회수 구조로 바꾸는 판단을 더했다. 장소를 한 페이지로 남겨 콘텐츠와 제품 가설이 떨어지게 하는 편이 반복 재사용에 맞다.
- 같은 리뷰와 2026-08-27~28 AI 뉴스는 모델 이름보다 라우팅, 장기 실행, 재개 가능한 작업 표면이 더 중요해지는 흐름을 보였다.
- `제품 적용`이 필요할 때는 먼저 라우팅 규칙을 종이 한 장으로 그려 본다.
