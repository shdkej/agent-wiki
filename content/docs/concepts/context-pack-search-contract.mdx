# 컨텍스트 팩 검색 계약

Context Pack은 요청마다 원문을 모두 읽게 하는 묶음이 아니라, 지금 작업에 필요한 필수 문서와 검색 범위를 고정하는 실행 계약이다.

## 승격 판단

- source: `source/openclaw-system/docs/DOCUMENT_SEARCH_PIPELINE.md`
- 핵심 주장: 요청은 먼저 route로 좁히고, 필수 문서와 Agent Wiki 검색 후보를 확인한 뒤, 부족할 때만 ingest 상태가 통과된 raw source를 읽는다.
- 재사용 이유: 에이전트가 README나 route 선언만 보고 판단을 끝내는 드리프트를 막고, 실제로 읽은 위키 페이지와 raw source 상태를 실행 기록에 남기게 한다.
- 중복 여부: `review-routing-currentness`는 리뷰 소스의 현재성 문제를 다루고, 이 문서는 모든 작업의 검색·근거 계약을 다루므로 별도 concept로 둔다.
- target: `content/docs/concepts/context-pack-search-contract.mdx`

## 실행 순서

1. 요청을 `infinity`, `product`, `travel`, `content`, `operations` 중 가장 좁은 route로 분류한다.
2. 공통 부팅 문서와 route 필수 문서를 먼저 읽는다.
3. Agent Wiki에서 semantic 후보를 찾고, 문자열 검증은 보조 신호로만 쓴다.
4. 위키 근거가 부족할 때만 허용된 `source/` 하위 경로를 검색한다.
5. raw source는 `reviewed`, `selected`, `integrated` 상태일 때만 근거 후보로 사용한다.
6. 실제로 읽은 위키 페이지, 검색어, raw source 경로와 상태를 작업 기록에 남긴다.

## 차단과 계속 진행의 경계

| 상황 | 처리 |
| --- | --- |
| 위키 후보가 없음 | `no-wiki-match`로 기록하고 외부 조사나 raw source 검색으로 계속한다. |
| 의미 후보는 있으나 정확 문자열이 없음 | `semantic-match-only`로 기록하고 후보 페이지를 읽은 뒤 판단한다. |
| 인덱스 준비 실패 또는 검색 도구 실패 | `preflight_failed`로 보고하고 근거 없는 완료 주장을 하지 않는다. |
| raw source가 `queued` 또는 `rejected` | 확정 지식으로 쓰지 않고, 필요하면 ingest 검토 후보로만 남긴다. |

## 오래 남길 원칙

- Context Pack은 경로와 범위를 고정하는 계약이지, 원문 사본이나 요약문이 아니다.
- 검색 결과가 없다는 사실은 작업 차단이 아니라 근거 한계를 표시하는 신호다.
- raw source를 쓸수록 출처와 ingest 상태를 더 분명히 남긴다.
- 공개 위키에는 query·lint·ingest 운영 로그를 넣지 않고, 별도 운영 로그에 남긴다.
