# 알던 것을 짧은 실행으로 닫는다

이미 알고 있는 기본기와 확인된 사례는 더 오래 분석하기보다 짧은 실행 루프로 옮긴다. 새 아이디어를 찾는 날에도 핵심은 경쟁 앱, 부족한 리뷰, 연결고리, 첫 테스트처럼 한 장으로 닫는 데 있다.

## 판단 순서

1. 문제를 새로 발명하기보다 이미 아는 패턴인지 먼저 본다.
2. 한 아이디어를 경쟁 앱 / 부족한 리뷰 / 인플루언서 연결고리 / 7일 첫 고객 테스트의 네 칸으로 압축한다.
3. 실행 단위를 일주일 안에 검증 가능한 크기로 줄인다.
4. 실행 뒤에는 다시 읽고 다음 행동을 정한다.
5. 감상보다 실제로 닫힌 결과를 남긴다.

## 왜 필요한가

- 이미 아는 것을 빨리 실행하면 정보 수집이 자기합리화로 길어지지 않는다.
- 작은 실행은 시장, 취향, 운영의 현실을 빨리 드러낸다.
- 큰 전략보다 첫 고객, 첫 결과물, 첫 반응이 다음 판단을 만든다.
- 실행 가능한 압축이 있어야 혼란스러운 아이디어도 다룰 수 있다.
