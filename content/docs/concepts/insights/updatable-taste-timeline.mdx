# 업데이트 가능한 감도는 타임라인으로 읽는다

지속적으로 갱신할 수 있는 주제는 한 번 예쁘게 만드는 것보다, 시간이 지나도 감도가 믿을 만하게 보이는지가 더 중요하다. 이 판단은 제품 아이디어, 콘텐츠 큐레이션, 레퍼런스 선택에 같이 적용된다.
좋은 타임라인은 결과물의 완성도보다, 만든 사람의 감도와 선택 기준을 오래 믿게 만든다.

## 판단 순서

1. 주제가 계속 업데이트될 수 있는지 먼저 본다.
2. 결과가 번지르르한지보다, 만든 사람의 감도가 오래 믿을 만한지 본다.
3. 허술함, 재치, 친근함이 함께 남아 있는지 본다.
4. 초기 홍보나 첫 화면보다, 시간이 쌓인 타임라인에서 같은 기준이 반복되는지 본다.
5. 한 번의 완성도보다 반복 가능한 신뢰 표면을 우선한다.

## 왜 필요한가

- 감도는 정적인 예쁨보다 누적된 신뢰에서 더 잘 보인다.
- 타임라인은 취향을 설명하는 메타데이터가 아니라, 취향이 실제로 유지되는지 보여 주는 증거다.
- 겉만 번지르르하면 새로움은 있어도 계속 갱신할 이유가 약해진다.
- 제품과 콘텐츠 모두, 사용자가 "이 사람 감도는 믿을 수 있다"고 느끼는 쪽이 재방문에 더 강하다.
- 허술함, 재치, 친근함이 같이 남아 있으면 감도는 더 오래 갱신 가능하다.
