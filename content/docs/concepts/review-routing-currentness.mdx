# 현재성 우선

지식과 추천은 최신 맥락을 먼저 고정한 뒤에만 재사용한다. 과거 기록은 현재 판단을 보강할 때만 쓰며, 현재 사실을 대체하지 않는다.

## 판단 원칙

1. 사용자의 현재 의도와 시점을 먼저 확인한다.
2. 원문, 컴파일 지식, 자동화 결과의 역할을 섞지 않는다.
3. 날짜·장소·상태가 달라졌다면 과거 자료는 근거가 아니라 참고로 취급한다.
4. 재사용 가능한 판단만 위키에 남기고, 작업 이력과 원문은 Knowledge Lab에 둔다.

## 왜 필요한가

오래된 맥락이 현재의 첫 행동을 덮어쓰는 드리프트를 막고, 사용자 판단과 자동화 처리를 구분하기 위해서다.
