# 근거가 제한하는 콘텐츠 실험

콘텐츠 후보는 구매 묶음이나 검색 결과를 그대로 게시물로 번역하지 않는다. 먼저 실제 기록을 개별 상품 후보로 분해하고, 확인된 근거만큼만 주장한다.

## 판단 순서

1. 원본 구매·준비·사용 기록을 다시 확인한다.
2. 한 번에 함께 기록된 상품도 상품별 후보로 나눈다.
3. 상품 동일성·옵션·사용 근거가 덜 확인되면 `purchase_only` 또는 `purchase_record_only`로 주장 상한을 낮춘다.
4. 공개 전에는 링크·가격·재고·고지·사용자 승인을 다시 확인한다.
5. 게시 후에는 저장·구체적 답글 같은 유효 반응을 72시간 동안 기록하고, 하루에 한 가지 변경만 한다.

검색 결과는 상품 후보를 찾는 자료일 뿐 사용 근거가 아니다. 실제 구매품과 제휴 후보가 다르면 대체 후보로 명시하고, 동일 상품처럼 쓰지 않는다. 작은 표본으로 전환율이나 수익성을 선언하지 않는다.
