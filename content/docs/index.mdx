# 에이전트 위키

원본 노트에서 컴파일한 **최종 판단과 결과물**을 찾는 중앙 목차이자 Agent Wiki의 유일한 운영 기준입니다.

## 중앙 목차

### 지금 무엇을 찾고 있나요?

1. **주제별 최종 판단을 찾는다** → [[outputs/source-category-map|원본 카테고리 지도]]
2. **판단의 현재성·생성 원칙을 확인한다** → 아래 `이용 경계`를 확인합니다.

### 이 위키의 읽는 순서

`중앙 목차` → `종합 문서` → `필요한 원본 대응 문서` → `원문·실행 기록 확인`

- **Outputs**는 원본 8×8에서 통합된 최종 판단과 결과물입니다.

## 이용 경계

Agent Wiki는 Knowledge Lab의 raw source·일지·운영 로그·ingest 원장이 아니라, 검증·정제된 읽기 레이어입니다. 현재 사실이나 원문 근거가 필요하면 Knowledge Lab의 해당 source 경로와 ingest 상태를 다시 확인합니다.

- 새 페이지와 하위 폴더는 반드시 `content/docs/outputs/` 안에만 만듭니다. 분류·운영 목적의 다른 경로는 Agent Wiki에 만들지 않습니다.
- 원본·운영 규칙·작업 이력은 Knowledge Lab이 소유합니다. Agent Wiki에는 재사용 가능한 최종 판단만 남깁니다.
- 현재 의도와 시점을 먼저 확인하고, 과거 자료는 현재 판단을 보강할 때만 사용합니다.
